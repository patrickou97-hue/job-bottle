# 拾星网申助手

拾星网申助手是拾星 StarJob 的 Manifest V3 浏览器扩展。它把用户主动同步到浏览器本地的拾星简历内容填写到当前网申页面。

扩展支持基础信息、教育、工作 / 实习、项目、技能、校园、获奖、证书和语言等常见字段；用户在拾星简历中明确保存后，性别、国籍 / 地区、期望工作地点和项目链接也可填写。项目区内只有“描述”或“职责描述”时，会对应到具体项目经历。填写方式包括“只填空白项”“覆盖已有内容”和用户主动选择的“AI 智能填写”。AI 模式会把简历当作事实依据，同时参考岗位描述、字段语义和所在经历记录：姓名、手机号、学校、公司、职位和日期等事实字段直接采用所选简历的对应记录，开放文本可以在证据范围内归纳和改写，不要求逐字复述简历，也不允许虚构公司、经历、数字或用户偏好。字段会按语义和预计输出量拆成小批次；每批分析完成后，扩展都会重新扫描当前表单、写入并回读，再继续下一批。服务端发现截断、缺项或格式错误时只重试缺失字段，必要时继续拆批。

## 1.1.3 可见字段识别与逐批写回

1.1.3 重新规定字段身份优先级：先看控件自身标签和用户眼前的局部排版，再看确定性字段键，最后才参考周边区块。页面顶部搜索框、手机号国家区号、公司类型等控件不会再冒充姓名、手机号或公司名称。姓名、手机号、学校、专业、公司、职位和起止时间等事实字段由所选简历直接确定，AI 负责开放描述和岗位化表达。长表单改为每分析一批就立即重新扫描、写入并回读一批；即使后续批次失败，已经核验成功的结果也会保留。

## 1.1.2 写回稳定性与字段防错位

1.1.2 统一服务端与扩展的 AI 接受阈值，让通过校验的 AI 改写优先写入，结构化简历值仅在模型未回答时兜底；学校、专业、公司、职位、日期、联系方式和链接改用字段级证据校验，防止毕业时间写入学校、课程列表写入作品链接。AI 分析完成后会重新扫描当前表单并把结果绑定到最新控件，降低动态页面重渲染后整组经历写入失败的概率。自定义下拉等待时间延长，手机号在页面已有国家区号选择器时不会重复写入 +86。

## 1.1.1 长表单批次扩容

1.1.1 将单次 AI 填写提升为最多 100 个串行批次、1500 个安全字段。常见的 19 批长表单会逐批完成分析，不再因旧的 15 批限制提前退出；仍然只有所有批次都返回完整结果后才统一写入页面，避免出现半页已填、半页失败。密码、验证码、身份证和敏感声明等排除规则不变。

## 1.1.0 AI Smart Fill V2

1.1.0 增加岗位上下文、ATS 供应商与公司画像识别，覆盖 Workday、Greenhouse、Lever、Moka、飞书招聘、北森、大易等常见结构，并能扫描开放 Shadow DOM。AI 请求带有操作、页面快照和批次身份，过期响应不会写回新页面。模型必须逐字段返回结果；输出截断、字段遗漏、重复键或格式异常都会触发定向修复，修复后仍不完整则整次失败并保持页面零写入。经历和日期继续依赖 1.0.1 的记录身份与回读校验，避免多段经历互相覆盖。

## 1.0.1 填写策略

1.0.1 为重复经历增加贯穿扫描、AI、解析与执行的 record identity。每个字段都携带 section、pageRecordId、recordIndex、resumePath 和唯一 elementIdentity；没有明确记录身份时不再默认取第一段经历。首次填写会等待页面 DOM 稳定并对语义指纹复扫，模型遗漏的确定性字段会按简历路径补齐。日期按同一记录的 start/end 语义和年/月/日部件填写，写入后必须回读一致才计为成功。

## 安全边界

- 只在用户点击“填写当前页面”后临时访问当前标签页。
- 不读取浏览历史、Cookie、密码或账号 CSV。
- 简历保存在 `chrome.storage.local`，卸载扩展时由浏览器清除。
- 不自动点击提交，不填写身份证、薪资、政治面貌、验证码等敏感字段。年龄只根据用户明确保存的出生日期计算；性别、国籍 / 地区和期望工作地点也只使用用户明确保存的内容，绝不推断。
- 文件上传、验证码、测评题和低置信度字段由用户手动完成。
- 普通模式的智能匹配只上传去内容化的字段元数据，不上传输入框现有值或简历正文；服务端结果必须通过标准字段键白名单校验。
- 只有用户主动选择“AI 智能填写”时，扩展才会把所选简历中去照片、去内部 ID 的结构化文字和非敏感页面字段发送到拾星服务端进行 AI 分析；不发送网申页面已有输入内容，请求不写入拾星数据库。
- AI 模式始终只填空白项。直接取自简历的值使用绿色边框，格式、选项或有证据的改写使用琥珀色边框，提交前必须由用户核对。

## 开发与打包

扩展目录本身即为可加载目录。仓库根目录执行：

```bash
npm run build:extension
```

脚本会读取 `manifest.json` 的版本号、校验必需文件，并生成对应版本的 ZIP。当前本地候选包为 `public/downloads/starjob-resume-assistant-v1.1.3.zip`，同时会在 `dist/` 生成中文文件名副本。1.1.3 保留跨 iframe 隔离和整次操作额度，并把每个 AI 批次重新绑定到写入时的最新页面控件；附件仍只允许手动上传。
