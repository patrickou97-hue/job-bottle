# 拾星网申助手

拾星网申助手是拾星 StarJob 的 Manifest V3 浏览器扩展。它把用户主动同步到浏览器本地的拾星简历内容填写到当前网申页面。

扩展支持基础信息、教育、工作 / 实习、项目、技能、校园、获奖、证书和语言等常见字段；项目区内只有“描述”或“职责描述”时，也会对应到具体项目经历。填写方式包括“只填空白项”“覆盖已有内容”和用户主动选择的“AI 智能填写”。AI 模式由拾星服务端完成分析，并从页面顶部开始按记录和字段顺序处理所有安全字段：能从所选简历明确回答的内容全部填写，能唯一确定的姓名拼音、格式转换、下拉或单选项也会填写；自我描述会以第一人称归纳有经历支撑的责任心、沟通与专业优势，经历描述和日期由扩展根据字段结构直接绑定到对应记录，不交给模型猜测。超过 50 个字段的大表单会按每批 50 个拆分，单页最多处理 750 个安全字段（最多 15 批）；弹窗展示真实批次进度与已用时，用户可随时取消，且只有所有批次成功后才统一写入页面。检测到超过 750 个安全字段时会在任何模型调用和页面写入前明确停止，并显示检测数量与上限，不会静默漏填后半页。

## 安全边界

- 只在用户点击“填写当前页面”后临时访问当前标签页。
- 不读取浏览历史、Cookie、密码或账号 CSV。
- 简历保存在 `chrome.storage.local`，卸载扩展时由浏览器清除。
- 不自动点击提交，不填写身份证、性别、年龄、薪资、政治面貌、验证码等敏感字段。出生日期仅在用户已于所选简历中明确保存时填写，绝不推断。
- 文件上传、验证码、测评题和低置信度字段由用户手动完成。
- 普通模式的智能匹配只上传去内容化的字段元数据，不上传输入框现有值或简历正文；服务端结果必须通过标准字段键白名单校验。
- 只有用户主动选择“AI 智能填写”时，扩展才会把所选简历中去照片、去内部 ID 的结构化文字和非敏感页面字段发送到拾星服务端进行 AI 分析；不发送网申页面已有输入内容，请求不写入拾星数据库。
- AI 模式始终只填空白项。直接取自简历的值使用绿色边框，拼音、格式或选项等派生值使用琥珀色边框，提交前必须由用户核对。

## 开发与打包

扩展目录本身即为可加载目录。仓库根目录执行：

```bash
npm run build:extension
```

脚本会读取 `manifest.json` 的版本号、校验必需文件，并生成对应版本的 ZIP。当前正式包为 `public/downloads/starjob-resume-assistant-v0.2.6.zip`，同时会在 `dist/` 生成中文文件名副本。旧版本继续兼容；建议升级到 0.2.6，以获得跨 iframe 字段隔离、最多 750 字段的完整分批处理、准确的部分失败提示、按整次操作计数的 AI 批次额度，以及不会每秒重复播报的无障碍进度。页面仍只会在全部 AI 分析批次成功后开始填写。
