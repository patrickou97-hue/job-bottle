# 拾星网申助手隐私说明

拾星网申助手只处理用户在拾星网站主动同步的简历内容，用于用户点击后填写当前网申页面。

- 数据保存在当前浏览器的扩展本地存储中。
- 不收集浏览历史、Cookie、密码、验证码或网申账号。
- “只填空白项”和“覆盖已有内容”中的智能匹配，只向拾星服务端发送字段标签、占位符、字段名、控件类型和所属区块，不发送输入框现有内容或简历正文。
- 只有用户主动选择“AI 智能填写”时，扩展才会把所选简历中去照片、去内部 ID 的结构化文字和非敏感页面字段发送到拾星服务端，并由服务端调用已配置的 MiMo。网申页面已有输入内容不会发送，这类请求不会写入拾星数据库；出生日期只在当前页面确有出生日期字段时随请求发送。
- AI 模式按页面顺序处理全部安全字段，但只填有简历明确依据的空白项，并对拼音、格式、选项或自我描述等派生值做特别标记。自我描述只允许整理简历原有事实；出生日期只有在用户已于所选简历中明确保存时才会填写，绝不从年龄、教育日期或证件号推断。证件、其他人口属性、薪资、法律声明、验证码、密码、其他主观申请题和提交操作仍由用户处理。
- 扩展内不包含服务密钥或远程执行代码。
- 不自动提交申请，用户必须检查并手动提交。
- 用户可以在扩展面板中随时清除本地简历数据。
